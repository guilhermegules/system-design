# Abstract Factory Pattern TypeScript

## How Run

- `npm install` for install all dependencies;
- `npm start` for build and run the `index.ts` file.

## Conceptual Example

This example illustrates the structure of the **Abstract Factory Method** design pattern and focuses on the following quesitons:

- What classes does it consist of?
- What roles do these classes play?
- In what way the elements of the pattern are related?
