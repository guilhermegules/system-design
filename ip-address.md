# IP Address

An IP address is a unique identifier assigned to a device on the internet or a local network. IP stands for Internet Protocol, which defines the rules for formatting and transmitting data across networks.

In simple terms, IP addresses allow devices to find and communicate with each other on a network. They contain location information that enables data to be routed correctly between devices. Without IP addresses, the internet would not be able to distinguish between different computers, routers, or websites.

## IP Versions

There are two primary versions of IP addresses used today.

### IPv4

The original Internet Protocol is IPv4. It uses a 32-bit numeric address written in dot-decimal notation, allowing for approximately 4 billion unique addresses.

Initially, this number seemed more than sufficient. However, as internet usage grew rapidly, the available address space began to run out.

Example: `102.22.192.181`

### IPv6

IPv6 was introduced in 1998 to address the limitations of IPv4. Its deployment began in the mid-2000s and continues today as internet usage continues to grow.

IPv6 uses 128-bit hexadecimal addresses, which dramatically increases the number of possible unique addresses.

It can support approximately 3.4 × 10³⁸ addresses, which is enough to meet global demand for the foreseeable future.

Example: `2001:0db8:85a3:0000:0000:8a2e:0370:7334`

## Types of IP Addresses

IP addresses can also be categorized based on how they are assigned and used.

### Public IP Address

A public ip address is assigned by an Internet Service Provider (ISP) and identifies your network on the internet. Typically, a single public IP address is shared by multiple devices within a network through a router.

Example: The IP address assigned to your home router by your ISP.

### Private IP Address

A private IP address is assigned to devices within a local network. These addresses allow devices such as computers, tablets, and smartphones to communicate with each other inside the same network.

Example: The IP addresses assigned by your home router to your devices.

### Static IP Address

A static IP address remains the same over time and is manually configured instead of being automatically assigned.

These addresses are generally more expensive but offer greater stability and reliability.

Common uses include:

- Server hosting
- Remote access
- Reliable geolocation services

### Dynamic IP Address

A dynamic IP address is automatically assigned by a DHCP (Dynamic Host Configuration Protocol) server and may change over time.

Dynamic IP addresses are the most common type used for consumer internet connections. They are cheaper to manage and allow networks to reuse IP addresses efficiently.

Example: Most home internet connections and personal devices use dynamic IP addresses.
